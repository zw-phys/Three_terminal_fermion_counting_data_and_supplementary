# Three_terminal_fermion_counting_data_and_supplementary
Source code, data processing of published articles, and supporting information.

The supplementary materials is also attached.


Data sources

- Preiss et al., Fig. 2(a) — https://arxiv.org/pdf/1811.12939v2
- Bojović et al., Fig. 5e — https://static-content.springer.com/esm/art%3A10.1038%2Fs41586-026-10356-3/MediaObjects/41586_2026_10356_MOESM5_ESM.xlsx

Scripts

- Fig_2_and_SupFig_2_Preiss_digitization.py — Digitizes Preiss data and plots Fig. S2.
- Fig_2_and_SupFig_3_Bojovic_frequencies.py — Converts Bojović frequencies to three-terminal probabilities.
- Fig_2_experimental_histograms.py — Plots the histograms and criteria in Fig. 2.
- SupFig_1_Fourier_geometry.py — Updates Fig. S1 labels and exports its data.
- SupFig_3_experimental_counting_constraints.py — Plots experimental counting constraints in Fig. S3.
- SupFig_4_three_particle_counting.py — Plots three-particle counting in Fig. S4.
- SupFig_5_four_terminal_counting.py — Plots four-terminal counting in Fig. S5.
